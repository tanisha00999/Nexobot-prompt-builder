# NEXOBOT Portfolio Prompt Generator v2

A simple static web app for the NEXOBOT student portfolio workshop.

## Workshop flow

1. Student enters name, class and city.
2. Student selects favourite subjects.
3. Student selects interests.
4. Student selects a future interest and can optionally add current learning/projects.
5. Student chooses website style and sections.
6. NEXOBOT generates a complete AI build prompt.
7. Student copies the prompt.
8. Student opens ChatGPT and pastes the prompt.
9. Student builds the website.
10. NEXOBOT teaches GitHub + Vercel deployment.

## Run locally

Open `index.html` in a browser.

No backend or installation is required.

## Deploy

This is a static website and can be deployed directly to Vercel or GitHub Pages.

## Version 3
Other selections in subjects, interests, future interests, and website styles reveal a custom text field. Custom answers are included in the generated prompt.
